# Claude AI Resources

This directory contains Claude-related resources for financial applications development and operations.

## Directory Structure

### `/claude/tasks`
Predefined tasks and prompts for Claude to perform financial-related operations:
- Data analysis tasks
- Report generation tasks
- Code review tasks
- Documentation tasks

### `/claude/skills`
Reusable skills and capabilities that Claude can use:
- Financial calculations
- Data processing workflows
- API integration skills
- Analysis techniques

### `/claude/subagents`
Specialized subagents for domain-specific tasks:
- Market analysis subagent
- Risk assessment subagent
- Portfolio optimization subagent
- Compliance checking subagent

## Usage

1. **Tasks**: Store task definitions in YAML or JSON format
2. **Skills**: Document skills with examples and use cases
3. **Subagents**: Define subagent capabilities and configurations

## Best Practices

- Document all prompts and their expected outputs
- Version control prompt changes
- Test prompts with sample data before production use
- Include examples of successful interactions
- Maintain a changelog for prompt updates
